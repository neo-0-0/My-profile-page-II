# My-profile-page-II


This is my submission for the HTML II assignment. I built a simple two-page website to show how to connect pages and use different HTML5 elements. 

## About the Project

On the main page (index.html), I set up the basic layout using semantic tags like header, nav, main, section, aside, and footer. It has a short intro about my school and hobbies, an audio and video player, an expandable details widget, and two iframes—one for a YouTube video and one for a Google Map showing Lagos.

The second page (contact.html) has a full registration form. I included all the required inputs like full name, email, password, gender radio buttons, checkboxes for hobbies, a country select dropdown, and a text area for messages. Both pages are linked together through the top navigation bar.
